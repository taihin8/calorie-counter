# Специфика проекта Daily_Journal

Общие правила — в `~/.dsh/AGENTS.md` (загружаются автоматически).

## Сборка APK и релиз

Сборка APK и релиз — [BUILD.md](BUILD.md) (по ссылке, при сборке).
Проверка APK без телефона — `test_apk.bat` (эмулятор `nova13`), подробности в BUILD.md.

Сборка с нативными уведомлениями требует двух проходов и отключённых desktop-
платформ — раздел «Нативные уведомления» в BUILD.md.

Из-под DSH обычный `flet build apk` зависает (дочерние процессы Python не пишут
вне рабочей папки). Рабочий обход — раздел «Сборка, когда Flutter/AppData вне
рабочей папки» в BUILD.md: окружение внутрь `.tmp\`, `FLET_CACHE_DIR`,
`JAVA_TOOL_OPTIONS=-Duser.home`, `--exclude .tmp`, убить Gradle-демоны.
Перед сборкой проверить место на диске: при нехватке `pip` падает с `[Errno 28]`.

## Веб-режим

Запускать веб только с `CALORIE_MODE=web` (иначе мьютекс блокирует десктоп):

```powershell
$env:CALORIE_MODE="web"
& ".\.venv\Scripts\python.exe" -u ".\.venv\Scripts\flet.exe" run --web main.py --port 8001
```

Без этой переменной веб держит мьютекс, и десктоп-копия при запуске молча завершается (exit 0, окно не появляется).
