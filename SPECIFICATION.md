## 4. Спецификация модуля «Будильник» (согласованная)

### 4.1 Модель будильника
| Поле | Тип | Примечание |
|---|---|---|
| `id` | long | автогенерация |
| `enabled` | bool | вкл/выкл тумблером |
| `days` | множество пн–вс | правило расписания только для этого будильника |
| `startTime` | HH:mm | окно начала |
| `endTime` | HH:mm | должно быть позже startTime; переход через полночь — не v1 |
| `interval` | 15 / 30 / 60 / 120 мин | фиксированный набор шагов |
| `soundId` | id встроенного трека | см. 4.5 |
| `melodyDuration` | 60 с | константа, не настраивается |

Имя — авто-«Будильник 1, 2…», поле имени не нужно. Таблица `alarms`
добавляется в существующую схему `init_db()`.

### 4.2 Правило расписания
1. Точки: `startTime + k·interval`, пока точка ≤ `endTime` (окончание
   включается).
2. Только в дни, отмеченные в `days` этого будильника.
3. Любое изменение настроек → немедленное перепланирование; каждый старт
   приложения → полный пересчёт.

Пример: 11:00–20:00, шаг 60 мин, будни → 11:00, 12:00, … 20:00 (10 звонков).

### 4.3 Срабатывание
- Мелодия играет ровно 1 минуту, без повторов.
- Нарастание громкости: первые ~10 с от тихого до полной, настройки нет.
- Останов: кнопка «Стоп» на экране звонка (Flet-страница).
- После минуты: звук прекращается, в списке остаётся «последний звонок:
  HH:mm» до ручного закрытия.

### 4.4 Экраны
1. Список будильников: тумблер, строка расписания («Будни · 11:00–20:00 ·
   каждый час»), строка последнего звонка, кнопка добавить.
2. Редактор: чекбоксы Пн–Вс + пресеты; time picker начала/окончания
   (валидация окончание > начало); сегменты интервала 15/30/60/120;
   выбор звука; Сохранить/Отмена/Удалить.
3. Выбор звука: список с превью (~5 с).
4. Экран звонка: Flet-страница, мелодия + «Стоп».

### 4.5 Звуки
Только встроенные, 4–5 треков с бесшовной петлёй: «Дождь», «Ручей», «Лес»,
«Озеро», «Ветер». Громкость = системная медиа-громкость × множитель
нарастания.

### 4.6 Граничные случаи
- `endTime ≤ startTime` → не сохраняется.
- Выключено/удалено → отмена запланированного срабатывания.
- Процесс убит / перезагрузка → срабатывания пропущены, не навёрстываются;
  при старте приложения расписание пересчитывается.
- Смена пояса → пересчёт по локальному времени.
- Перевод часов: несуществующее время пропускается, повторяющееся —
  одно срабатывание.

### 4.7 Вне объёма v1
Нативный `AlarmManager` (v2), системные уведомления, full-screen,
повторы мелодии, snooze, вибро, таймер сна, свои аудиофайлы, виджет,
синхронизация, английская локаль.
