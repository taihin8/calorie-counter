# Откат изменений

рабочее состояние одной командой, не разбирая коммиты вручную.

```powershell
# вернуть только внешний вид
git checkout checkpoint-before-styling-2026-11-13-1156 -- screens/diary.py screens/login.py services/ui_style.py
```

## Как откатиться

```powershell
# посмотреть, что изменилось с точки отката
git diff checkpoint-before-styling-2026-11-13-1156

# вернуть ВСЁ к точке отката (рабочие файлы тоже)
git reset --hard checkpoint-before-styling-2026-11-13-1156

# или только один файл
git checkout checkpoint-before-styling-2026-11-13-1156 -- screens/diary.py
```

Настройки в базе (шрифты, темы, будильники) откат кода не трогает.
