# Откат изменений

Перед рискованными правками создаём точку отката. Так можно вернуть
рабочее состояние одной командой, не разбирая коммиты вручную.

## Точка отката перед работой над стилями (2026-11-13)

| Что | Значение |
|---|---|
| Коммит | `aa0981c` (docs: актуализировать спецификацию) |
| Тег | `checkpoint-before-styling-2026-11-13-1156` |
| Ветка-бэкап | `backup/before-styling-2026-11-13-1156` |
| Тесты | 103 passed |
| Версия | 1.1.1 (не выпущена) |
| APK | sha256 `9358c645…4269ae` |

Что работает в этой точке: будильник звенит при свёрнутом приложении
(foreground-сервис), напоминания приходят при закрытом приложении, поле
даты в напоминаниях в границах экрана, размеры шрифта 10/12/14.

## Как откатиться

```powershell
# посмотреть, что изменилось с точки отката
git diff checkpoint-before-styling-2026-11-13-1156

# вернуть ВСЁ к точке отката (рабочие файлы тоже)
git reset --hard checkpoint-before-styling-2026-11-13-1156

# или только один файл
git checkout checkpoint-before-styling-2026-11-13-1156 -- screens/diary.py
```

Настройки в базе (шрифты, темы, будильники) откат кода не трогает.
